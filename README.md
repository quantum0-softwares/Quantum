# Quantum

### Download & Installation

Head over to the **[Releases](https://github.com/quantum0-softwares/Quantum/releases/latest)** tab to grab the latest build:

| File | Type | Description |
| :--- | :--- | :--- |
| **`QuantumSetup.exe`** | **Installer (Recommended)** | Installs to your local user directory and checks for updates automatically. |
| **`Quantum-Portable.zip`** | **Portable** | Standalone archive. Extract anywhere and launch `Quantum.exe` directly without installing. |

#### System Requirements
* **OS:** Windows 10 (64-bit) or Windows 11
* **Runtime:** Microsoft Edge WebView2 Runtime *(Included by default on modern Windows; the installer will notify you if it is missing).*
